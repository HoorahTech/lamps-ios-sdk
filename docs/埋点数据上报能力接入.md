# 埋点数据上报能力接入

游戏中心和单个游戏的打开、退出，由 SDK 回传给宿主，宿主自己上报。未设置回调时不会调用。请在主线程设置，回调里不要做耗时操作。

SDK 只给出本次行为字段。宿主自行补 `model`、外层 `event` / `type`、用户或游客标识、事件时间和客户端版本。

`showGameCenter` / `showGame` 的 `completion` 只表示跳转已发起，不是埋点。内嵌 `makeGameCenterView` 本身不回传；从里面再打开的单个游戏仍会回传。

## 1. 设置回调

回调参数是一个 `LampsBehavior`。

| 字段 | 说明 |
| --- | --- |
| `event` | `openPage` 打开页面，`exitPage` 退出页面。埋点事件名用 `event.name`：`打开页面` / `退出页面` |
| `pageType` | `gameCenter` 游戏中心，`game` 单个游戏。埋点文案用 `pageType.name`：`游戏中心` / `游戏` |
| `data` | 本次业务字段。打开时传入的 `trackParams` 会按键平铺进来，与 SDK 字段同名时保留 SDK 的值 |
| `trackParams` | 打开时传入的原表。没传就是空字典 |

# Swift

```swift
Lamps.behaviorHandler = { behavior in
    let eventName = behavior.event.name          // 打开页面 / 退出页面
    let pageName = behavior.pageType.name        // 游戏中心 / 游戏
    let data = behavior.data
    let trackParams = behavior.trackParams
    // data 放进宿主埋点。外层 type：打开用 action，退出用 view
}

// 清除
Lamps.behaviorHandler = nil
```

# Objective-C

```objc
[Lamps setBehaviorHandler:^(LampsBehavior *behavior) {
    NSString *eventName = [Lamps behaviorNameForEvent:behavior.event];
    NSString *pageName = [Lamps behaviorPageTypeNameForPageType:behavior.pageType];
    NSDictionary *data = behavior.data;
    NSDictionary *trackParams = behavior.trackParams;
}];

// 清除
[Lamps setBehaviorHandler:nil];
```

事件枚举：`LampsBehaviorEventOpenPage` / `LampsBehaviorEventExitPage`。页面类型：`LampsBehaviorPageTypeGameCenter` / `LampsBehaviorPageTypeGame`。

## 2. 打开时带上埋点字段

`trackParams` 写在本次打开的配置里，之后的打开成功、打开失败和退出都会带回。`urlQuery` 只拼到页面链接上，不进埋点。

从游戏中心再打开的游戏，会带上中心这次的 `trackParams`，打开成功、打开失败和退出都带回。内嵌 `makeGameCenterView` 本身仍不回传。直接 `showGame` / `presentGame` 用游戏自己的 `LampsGameConfig.trackParams`。

# Swift：游戏中心

```swift
let config = LampsGameCenterConfig(dayNightMode: .night)
config.urlQuery = ["from": "home"]
config.trackParams = ["entrance": "home_icon"]
Lamps.showGameCenter(from: self, config: config)
Lamps.presentGameCenter(from: self, config: config)
```

# Swift：单个游戏

```swift
let config = LampsGameConfig()
config.urlQuery = ["from": "banner"]
config.trackParams = ["entrance": "home_banner"]
Lamps.showGame(gameId: "2", from: self, config: config)
Lamps.presentGame(gameId: "2", from: self, config: config)
```

# Objective-C：游戏中心

```objc
LampsGameCenterConfig *config = [[LampsGameCenterConfig alloc] initWithDayNightMode:LampsDayNightModeNight];
config.urlQuery = @{@"from": @"home"};
config.trackParams = @{@"entrance": @"home_icon"};
[Lamps showGameCenterFromViewController:self config:config completion:nil];
[Lamps presentGameCenterFromViewController:self config:config completion:nil];
```

# Objective-C：单个游戏

```objc
LampsGameConfig *config = [[LampsGameConfig alloc] init];
config.urlQuery = @{@"from": @"banner"};
config.trackParams = @{@"entrance": @"home_banner"};
[Lamps showGameWithGameId:@"2" fromViewController:self config:config completion:nil];
[Lamps presentGameWithGameId:@"2" fromViewController:self config:config completion:nil];
```

## 3. 什么时候回调

打开：页面视图加载时回传一次 `openPage`，`data.status` 为 `成功`。不等 H5 加载完成。同一次访问只回传一次，从游戏返回游戏中心不会再次报打开。

失败：页面没创建出来时回传一次 `openPage`，`data.status` 为 `失败`。H5 加载失败、白屏、失败页点重试，不再改这次打开结果，也不会再补发一次成功。

退出：只有先报过打开成功，页面真正关掉时才回传 `exitPage`。加载失败后用户关掉页面，也会回传退出。激励视频盖住页面、从游戏中心再打开游戏，都不算退出。

停留时长从页面视图加载开始算，白屏和失败页上的时间也计入，进后台的时间不计。

## 4. 打开页面的 data

| 字段 | 说明 |
| --- | --- |
| `type` | `游戏中心` 或 `游戏`，与 `pageType.name` 相同 |
| `status` | `成功`：页面视图已加载。`失败`：页面没创建出来 |
| `id` | 单个游戏为游戏 ID。游戏中心为 `NSNull` |
| `code` | 失败为错误码。成功为 `NSNull` |
| `message` | 失败为错误描述。成功为 `NSNull` |
| 其余键 | 本次 `trackParams`。与上面同名的键不会覆盖 |

失败一共 5 个错误码。`domain` 为 `com.hupu.lamps.sdk`。

| code | message | pageType | 场景 |
| --- | --- | --- | --- |
| -1001 | 尚未调用 Lamps.start | 游戏中心 | 打开游戏中心时还没 `start` |
| -1001 | 尚未调用 Lamps.start | 游戏 | 直接打开游戏时还没 `start` |
| -1002 | gameId 不能为空 | 游戏 | `gameId` 为空或只有空白 |
| -1009 | 游戏中心地址不可用 | 游戏中心 | 游戏中心地址为空，或不是合法 URL |
| -1010 | 找不到可用于打开游戏中心的页面 | 游戏中心 | 没传页面，也找不到当前最上层页面 |
| -1010 | 找不到可用于打开游戏页的页面 | 游戏 | 直接打开游戏时找不到宿主页面 |
| -1010 | 无法找到打开游戏页的容器 | 游戏 | 游戏中心 H5 `lamps.game.open` 找不到容器 |
| -1011 | 游戏页地址不可用 | 游戏 | 游戏页地址为空，或替换游戏 ID 后不是合法 URL |
| -1011 | url 无效，须为完整 http(s) URL | 游戏 | 游戏中心 H5 传入的地址不是完整 http(s) URL |

## 5. 退出页面的 data

| 字段 | 说明 |
| --- | --- |
| `type` | `游戏中心` 或 `游戏` |
| `duration` | 本次前台秒数，向下取整。进后台不计。游戏中心包含其中的浏览和游戏时间 |
| `game_list` | 见下表 |
| 其余键 | 本次 `trackParams`。与上面同名的键不会覆盖 |

`game_list` 每一项：

| 字段 | 说明 |
| --- | --- |
| `id` | 游戏 ID |
| `duration` | 这一局的前台秒数 |
| `ad_req` | 激励视频请求次数。一次 `lamps.ad.showRewardedVideo` 真正开始请求计 1 次，多个代码位不加 |
| `ad_show` | 展示成功次数 |
| `ad_clk` | 点击次数 |
| `price` | 曝光成功的竞胜价，单位分。没有广告时为 `0` |

直接打开的游戏，退出时 `game_list` 只有这一局。从游戏中心进入的游戏，退出游戏回传这一局，同时按游戏 ID 累加进该次中心访问。退出中心时 `game_list` 是合并后的列表。两边都会带上同一次游玩，宿主不要再加总。
